# HeySolo Manager

[English](README.md) | **فارسی**

HeySolo Manager ابزاری برای نصب و مدیریت متاتریدر ۵ روی سرورهای لینوکس Debian و Ubuntu است. متاتریدر از طریق Wine و یک محیط دسکتاپ سبک اجرا می‌شود و با VNC قابل دسترسی است.

## امکانات

- آماده‌سازی خودکار سرور Debian/Ubuntu
- نصب متاتریدر ۵ و مدیریت ترمینال‌ها
- راه‌اندازی Wine، VNC، دسکتاپ، والپیپر و تسک‌بار
- روشن، خاموش، ری‌استارت، حذف و بازیابی ترمینال‌ها
- همگام‌سازی فایل‌های MQL5 شامل Experts، Include، Indicators، فایل‌های set و Templates
- بکاپ و بازیابی
- عیب‌یابی، لاگ‌ها، آپدیت و حذف کامل
- پشتیبانی از چند ترمینال MT5 روی یک سرور

## حداقل سیستم موردنیاز برای یک متاتریدر

برای اجرای **یک ترمینال متاتریدر ۵** از طریق Wine، حداقل عملی پیشنهادی این است:

- Debian 11+ یا Ubuntu 22.04+ با معماری x86_64
- ۱ هسته پردازنده مجازی (۱ vCPU)
- ۱ گیگابایت RAM
- ۲ گیگابایت Swap پیشنهاد می‌شود
- ۲۰ گیگابایت فضای خالی دیسک
- دسترسی root یا کاربری با `sudo`
- دسترسی اینترنت برای دانلود پکیج‌ها و فایل نصب

این اعداد حداقل عملی برای یک ترمینال هستند. اکسپرت‌های سنگین، نمودارهای زیاد، بک‌تست یا اجرای دسکتاپ/VNC ممکن است CPU و RAM بیشتری نیاز داشته باشد.

## نصب

دستور زیر را با کاربر root اجرا کنید:

</div>

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Mahersaber2024/Heysolo/main/heysolo.sh)
```

<div dir="rtl">

بعد از نصب اول، هر بار فقط کافی است پنل مدیریت را با این دستور باز کنید:

</div>

```bash
sudo heysolo
```

<div dir="rtl">

از داخل پنل می‌توانید سرور را آماده کنید، ترمینال نصب یا اضافه کنید، دسکتاپ لینوکس را تنظیم کنید و نگهداری یا حذف را انجام دهید. اسکریپت‌های جانبی را مستقیم اجرا نکنید، مگر برای نگهداری پیشرفته.

## نصب دستی از روی سورس

</div>

```bash
git clone https://github.com/Mahersaber2024/HeysoloPublic.git
cd HeysoloPublic
sudo bash heysolo.sh
```

## اتصال با VNC

برای دیدن دسکتاپ متاتریدر، یک برنامه VNC Viewer روی کامپیوتر خودتان نصب کنید و به آدرس `SERVER_IP:5901` (یا پورتی که پنل نشان می‌دهد) با رمز VNC که هنگام نصب تعیین کرده‌اید وصل شوید.

- دانلود مستقیم VNC Viewer نسخه 7.15.1: [دانلود از سافت۹۸](https://dl2.soft98.ir/soft/u-v/VNC.Connect.Viewer.7.15.1.rar?1791992033)
- دانلود از سایت رسمی RealVNC: [realvnc.com](https://www.realvnc.com/en/connect/download/viewer/)

## مسیرهای نصب

</div>

```text
/opt/heysolo/scripts       اسکریپت‌های مدیریت
/opt/heysolo/bot           فایل‌های اجرایی و تنظیمات
/opt/heysolo/bot/MT5       فایل‌های MQL5
/opt/heysolo/bot/Meta5     نصب‌کننده‌های MT5
/etc/heysolo-mt5           وضعیت و تنظیمات ترمینال‌ها
```

## مدیریت ترمینال‌ها

از پنل برای نصب و اضافه کردن ترمینال، روشن و خاموش کردن، نمایش روی دسکتاپ، همگام‌سازی فایل‌های MQL5، عیب‌یابی، آپدیت و حذف استفاده کنید.

فایل‌های MQL5 در آپدیت‌های معمولی حفظ می‌شوند و فقط وقتی خودتان همگام‌سازی اجباری را بزنید بازنویسی می‌شوند.

## امنیت

هیچ‌وقت رمز عبور، توکن، کلید خصوصی، سرتیفیکیت، اطلاعات مشتری یا تنظیمات سرور واقعی را در مخزن قرار ندهید. پورت‌های VNC و مدیریت را محدود کنید، سیستم‌عامل را به‌روز نگه دارید و قبل از اجرای اسکریپت‌ها با دسترسی root آن‌ها را بررسی کنید.
